# EL2.0 项目

## 项目概述

EL2.0 是一个集成了前端工作流管理、后端API服务、数据加载与处理、GEE(Google Earth Engine)集成以及AI问答系统的综合平台。项目采用前后端分离架构，旨在为遥感数据处理、分析和应用提供完整的解决方案。

## 核心功能

### 1. 前端工作流管理
- 基于vue-flow实现的工作流可视化编辑器
- 支持节点的创建、连接和执行
- 实现了单线串行执行逻辑
- 包含工作流测试面板

### 2. 后端API服务
- Flask框架提供RESTful API
- 支持影像上传和YOLO模型预测
- 提供中国地理数据访问
- 数据集搜索和管理接口
- GEE影像处理接口
- RAG(Retrieval-Augmented Generation)问答接口

### 3. 数据加载与管理
- `easyDataset.py`：数据集管理工具，支持按时间、名称、频率筛选
- `chroma_tool.py`：向量数据库工具，用于存储和检索遥感数据集元数据
- `rag_tool.py`：基于向量数据库的问答系统，集成通义千问模型

### 4. GEE集成
- `AwesEE.py`：GEE影像处理工具，支持影像集筛选、处理和可视化
- 提供影像获取、筛选、处理和地图URL生成功能

### 5. 影像处理
- 集成YOLO目标检测模型
- 支持影像上传和预测结果返回

### 6. 地理数据可视化
- 基于Web的地理数据可视化平台
- 交互式地图操作、多尺度数据展示

## 快速开始

### 后端服务
1. 安装依赖：
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. 启动服务：
   ```bash
   python app.py
   ```

### 前端开发
1. 安装依赖：
   ```bash
   npm install
   ```

2. 启动开发服务器：
   ```bash
   npm run dev
   ```
